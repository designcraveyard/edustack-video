# Storytelling best practices (educational explainer)

## The 5-second hook

Every video opens with a **question the viewer wants answered** or a **counterintuitive observation**. Not a definition. Not a logo. Not "today we'll learn about…".

- ❌ "Today, we'll learn about photosynthesis."
- ✅ "How do leaves *eat sunlight*?"

## Concrete before abstract

Introduce a phenomenon visually before naming it. "A plant in a dark closet wilts" → then label it photosynthesis. Class 1–6 especially: NEVER lead with the term.

## One concept per beat

A beat = one idea. If a beat's narration mentions two distinct mechanisms, split it. Animation needs single-focus shots; layered ideas blur visually.

## Show, don't define

When the script must define a term, immediately follow with the visual that makes the definition redundant.

## Recap as payoff, not summary

The recap beat should let the viewer feel they *figured it out*, not be told what they learned. "Now you can spot a thirsty plant — that's photosynthesis going quiet."

## Pace

Hindi runs ~10% slower than English at the same word count. For Hindi target ~135 wpm; English ~150 wpm. The script writer should size beats accordingly.

## Tone (class-level matrix)

| Class | Tone | Vocabulary ceiling |
|---|---|---|
| 1–3 | warm, exclamatory, lots of "you" | top 1000 words |
| 4–6 | curious, occasional metaphor | top 3000 words |
| 7–9 | precise, occasional jargon with payoff | core academic |
| 10–12 | expert-friendly, allow technical terms | unrestricted |
